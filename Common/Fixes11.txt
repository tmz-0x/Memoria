4. CREATIVE BUT PERFORMANCE-SAFE ANIMATION

Use creativity where it improves the cinematic experience.

However, performance is more important than adding visual effects.

Avoid:

huge numbers of DOM elements
continuously changing React state for animation
expensive blur filters running continuously
excessive backdrop-filter usage
large canvas particle systems unnecessarily
unnecessary JavaScript animation loops
continuously recalculating layout
expensive box-shadow animations
unnecessary image duplication
animation libraries for effects that can be achieved efficiently with CSS

Prefer:

CSS transform
CSS opacity
CSS transitions
CSS keyframes
GPU-friendly compositing
requestAnimationFrame only when genuinely necessary
existing animation infrastructure where possible

Animations should primarily use:

transform + opacity

instead of repeatedly modifying:

top, left, width, height, etc.
