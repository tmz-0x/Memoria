MEMORIA'26 — FIX 4
Stronger Interactive Spotlights + More Visible Atmospheric Dust

IMPORTANT: This is a modification pass on the EXISTING Memoria'26 website.

Do NOT rebuild the project from scratch.

First inspect the existing implementation, especially:

CinematicIntro

Preserve the existing architecture, routing, styling, ticket system, admin system, approval system, check-in system, and all functionality that is already working.

This Fix 4 specifically improves the visual visibility and intensity of the spotlight and dust effects.

1. CINEMATIC INTRO — TWO MAIN FIXED SPOTLIGHTS

The cinematic intro has two main fixed spotlights.

They must remain:

fixed in their physical position
fixed in their rotation
fixed in their direction
NOT move horizontally
NOT move vertically
NOT rotate
NOT follow the mouse as an object

The spotlight beams themselves stay fixed.

BUT:

The LIGHT INTENSITY / BRIGHTNESS / ILLUMINATION of the two main spotlights must respond strongly to mouse movement.

Think of the mouse as controlling the energy/intensity of the lights, not their position.

2. MAIN SPOTLIGHT MOUSE INTERACTION

When the mouse moves across the cinematic intro:

the two fixed spotlights should become noticeably brighter/dimmer
the light should feel like it is reacting to the viewer
the illuminated stage area should visibly change in intensity
the beam glow should become more noticeable
the central illuminated area should respond smoothly
use smooth interpolation/easing

Do NOT make the effect instant or flickering.

The response should feel:

cinematic → theatrical → atmospheric → smooth → premium

IMPORTANT:

The spotlight should be MORE VISIBLE than in the previous version.

Increase the visual presence of:

spotlight beam
beam opacity
beam glow
stage illumination
bloom
light falloff
illuminated area

But do NOT make the entire screen white.

The background should remain dark and mystical.

3. TWO MAIN SPOTLIGHTS — VISUAL TARGET

The two main spotlights should clearly look like real theatrical stage lights.

They should have:

clearly visible beams
soft volumetric glow
brighter center
soft feathered edges
subtle atmospheric haze
visible light cone
realistic falloff
cinematic bloom

The beams should be visible even when the mouse is near the center.

Mouse movement should amplify/reduce their brightness rather than making them disappear completely.

Suggested intensity range

Use a noticeable range such as:

minimum intensity: approximately 0.45–0.60
normal intensity: approximately 0.70–0.85
maximum intensity: approximately 1.00–1.20

Adjust these values based on the existing visual implementation.

Do not blindly use these numbers if the current rendering system requires different values.

4. OTHER FIXED SPOTLIGHTS

The cinematic intro also contains other sub/fixed spotlights.

These must remain fixed in:

position
rotation
direction

They should NOT physically move.

However, their brightness/intensity should also react considerably to mouse movement.

Make this effect clearly visible.

For example:

When the mouse moves toward one region:

nearby/sub spotlight brightness increases
other spotlights can become slightly dimmer
light distribution changes subtly
the stage atmosphere feels alive

When the mouse moves away:

brightness smoothly transitions back

Do NOT make these lights completely synchronized.

Each sub-spotlight should have slightly different:

intensity
response strength
delay
fade timing

This creates a more realistic theatrical lighting system.

5. IMPORTANT — NO SPOTLIGHT POSITION MOVEMENT

Do NOT accidentally reintroduce the behavior from earlier versions.

The cinematic intro spotlights must NOT:

❌ follow mouse X position
❌ follow mouse Y position
❌ translate with mouse
❌ rotate toward mouse
❌ orbit
❌ pan
❌ tilt
❌ move across the stage

Only:

BRIGHTNESS + GLOW + LIGHT INTENSITY

may react to the mouse.

The physical spotlight geometry remains fixed.

6. MOUSE RESPONSE SHOULD BE CLEARLY NOTICEABLE

The previous version was too subtle.

Increase the difference between:

mouse away → normal/dim lighting

mouse near the light's influence → clearly brighter lighting

The user should immediately notice:

"The lights are reacting to my mouse."

But it should still feel sophisticated rather than like a game UI.

Avoid React state updates for every frame.

10. MAKE THE DUST VISIBLY MOVING

This is very important.

The particles should not look like static dots placed on the background.

The user should be able to clearly notice that they are slowly moving.

Use:

very slow drifting
subtle floating motion
different movement directions
different speeds
small vertical movement
small horizontal movement
gentle random paths
slight opacity variation

The movement should be:

SLOW + ORGANIC + CONTINUOUS

Not:

FAST + RANDOM + DISTRACTING

The user should notice the atmosphere after watching the page for a few seconds.

Increase the number of particles compared with the previous implementation.

Desktop:

approximately 60–90 particles per major public section, depending on performance.

Mobile:

approximately 25–45 particles per section.

Do not create excessive DOM elements if the existing architecture can use a single canvas or efficient particle layer.

Prefer a performant implementation.

12. DUST VISIBILITY

contrast against the dark background
